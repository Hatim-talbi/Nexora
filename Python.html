🐍 Python

Professeur : Sara El Mansouri — 6 ans d'expérience

Cette formation vous accompagne progressivement dans l'apprentissage de Python, l'un des langages de programmation les plus utilisés aujourd'hui. Vous apprendrez les variables, les conditions, les boucles, les fonctions, les listes, les dictionnaires et les structures de données. Vous réaliserez également plusieurs exercices et projets pratiques afin de développer votre logique de programmation. La formation constitue une excellente base pour poursuivre ensuite vers l'automatisation, le développement logiciel ou la Data Science.
