⚡ JavaScript

Professeur : Adam Benali — 7 ans d'expérience

Cette formation est consacrée à JavaScript, un langage essentiel pour créer des sites web modernes et interactifs. Vous apprendrez à manipuler les variables, conditions, boucles, fonctions, tableaux et objets, puis vous découvrirez le DOM et les événements pour contrôler les éléments d'une page web. La formation introduit également les bases de Node.js afin de comprendre comment JavaScript peut être utilisé côté serveur. Des projets pratiques vous permettront de mettre directement vos connaissances en application.
